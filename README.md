# LaTeX paper template

My personal LaTeX template for writing papers, tailored to the journals I usually submit to.

Includes a manuscript and supplementary information in one PDF, with reference presets for **APA 7, APSR, AJPS, JOP, POQ, JASA, and JRSS B**.

Download the whole folder, open `main.tex` in Cursor, and press **Cmd+S** after editing. Requires LaTeX Workshop and a full LaTeX installation. The included settings handle compilation and cleanup.

Choose the [reference preset](reference-styles/README.md) in `preamble.tex` (default: `apsr`).
